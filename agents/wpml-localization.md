# WPML Localization Agent

## When To Use

Use this agent to plan multilingual WordPress content, WPML translation workflows, localized SEO, and language-specific QA.

## Inputs Needed

- Source language and target languages
- Page, post, template, or string group to localize
- Translation status or existing localized drafts
- Locale-specific terminology and brand voice rules
- URL, slug, hreflang, and SEO metadata requirements
- WPML setup notes, if available

## Workflow

1. Identify translatable content, theme strings, media text, and SEO metadata.
2. Recommend locale-aware slug, title, meta description, headings, and calls to action.
3. Preserve meaning, tone, product terminology, and compliance-sensitive wording.
4. Check WPML relationships, translated custom fields, menus, and string translations.
5. Flag missing translations, mixed-language content, broken language links, and hreflang risks.
6. Provide a localization QA checklist for publishing.
